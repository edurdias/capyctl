# Code of conduct

We want people with different experience and backgrounds to be able to ask
questions, report problems and contribute to mllm.

Be respectful and specific. Critique ideas and code, not people. Assume that a
question may come from someone learning, accept corrections, and respect another
person's request to end an interaction. Do not harass, threaten, discriminate,
make unwelcome sexual comments, publish private information or deliberately
disrupt discussions.

These standards apply to this repository's issues, pull requests and other
project spaces, and when someone represents the project elsewhere. Maintainers
may edit or remove harmful content, close or lock discussions, and restrict
participation when needed. Enforcement should be proportional to the behavior
and protect affected participants.

To report abuse privately, use GitHub's **Report content** or **Report abuse**
action on the relevant content or profile; see
[GitHub's reporting guide](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).
Do not repost abusive content or another person's private details in a public
issue. GitHub handles reports under its own policies. Maintainers can moderate
project spaces but cannot promise confidentiality for material already posted
publicly or guarantee a response time.
