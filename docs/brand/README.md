# Brand

CapyCTL's logos and icons, generated from the owner's original artwork by
`scripts/brand/build.py` (the originals are large and are not committed).
Rebuild with `python3 scripts/brand/build.py <originals folder>`; the file
names below stay the same.

| File | Use |
|---|---|
| `logo-dark.png`, `logo-light.png` | full logo with tagline, for dark and light backgrounds (README header) |
| `horizontal-dark.png`, `horizontal-light.png` | horizontal lockup |
| `wordmark-dark.png`, `wordmark-light.png` | the name, no mascot |
| `wordmark-dark-transparent.png`, `wordmark-light-transparent.png` | the name on transparency, for any background |
| `mark-dark.png`, `mark-light.png` | mascot, arc and terminal, no text |
| `icon.png` | head and prompt on a rounded square, transparent corners (favicons) |
| `app-icon.png` | mascot on a rounded square, transparent corners |
| `avatar.png` | mascot in a circle, transparent corners (GitHub and social avatars) |
| `social-preview.jpg` | 1280 × 640, for the repository's social preview |

The site uses its own copies under `site/public/` (`favicon.ico`,
`favicon-32.png`, `apple-touch-icon.png`, `icon-512.png`, `og.jpg`, and
`brand/*.webp`: hero logos and header lockups). All files are raster; there is no vector master yet.
